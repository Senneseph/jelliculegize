# jcule-cmd

This is a standard app we will build which will take a normally command line software package and attempt to build a jcule UI for it.

For example, we have FFMPEG with its command line options and outputs.  We document all of these as an OpenAPI specification and then we separately decide how we want to build a flexible UI for it.  It's essentially a WYSIWYG Drag n' Drop, editable UI.
